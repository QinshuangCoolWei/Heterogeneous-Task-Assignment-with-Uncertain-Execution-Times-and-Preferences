# Heterogeneous-Task-Assignment-with-Uncertain-Execution-Times-and-Preferences

This is the extended version and the code generated for the simulation of paper: Heterogeneous Task-Assignment with Uncertain Execution Times and Preferences
We have submitted the short version of paper to LCSS and CDC 2025.[Extended Version](https://pages.github.com/)

Files:
extended_ver_Task_assignment.pdf: the extended version to the paper we submitted to LCSS and CDC, given the length limitation, we leave all the proofs of the theorems in the appendix of this extended version.
Bandit.m: The main bandit algorithm that and other helper functions.
approx_gap.m: A helper function that calculates an approximated solution to the GAP task assignment problem in (6).
