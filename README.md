# Heterogeneous-Task-Assignment-with-Uncertain-Execution-Times-and-Preferences

This is the supplementary material of paper: Heterogeneous Multi-Agent Task-Assignment with Uncertain Execution Times and Preferences <br /> 
This paper has been submitted to IEEE Transactions on Automatic Control <br /> 

Files:\
Bandit_feas.m and Bandit_feas_Large.m : The main bandit algorithm, including the helper functions.<br /> 
plot_bandit.m and plot_large.m: The visualization scripts.<br /> 
<br /> 
The results obtained from running the bandit algorithms are more than 1GB for each file and are too large for uploading, so we kept the results in our local files. <br /> 
Readers who are interested in the results but do not want to run the whole process can ask for the result dataset via email: sheilaloveseating@gmail.com .
